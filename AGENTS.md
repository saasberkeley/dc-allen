# Collaboration preference

Unless the user explicitly asks the assistant to finish a task independently, keep the user in the loop before major actions. Explain in plain language:

- what question the next step answers;
- why the step is needed;
- what will be changed or run;
- what output to expect; and
- how the possible results should be interpreted.

Work in visible checkpoints. Report each checkpoint's findings and proposed next step before starting another major analysis, long-running job, broad code change, Git operation, or external action. Small read-only inspections and routine verification may proceed without waiting, but should be summarized at the next checkpoint.
